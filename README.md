Career Verse

Career Verse is a full-stack career development platform that integrates a Stack Overflow–style Q&A forum, an AI-powered resume analyzer, and a job portal into a single ecosystem designed to support learners, job seekers, and professionals. The Q&A community enables users to ask questions, share solutions, and interact through tags, upvotes, and user reputation, creating a collaborative learning environment. The AI Resume Analyzer allows users to upload their resumes and receive ATS-style scoring, missing skill identification, and personalized suggestions using NLP and machine-learning models. The Job Portal helps candidates explore opportunities, filter job listings, and apply directly through the platform while offering companies an easy way to post and manage openings.

The project is built using a modern tech stack, featuring a responsive frontend (Flutter/React), a secure backend (Node.js/Express), and a reliable database (MongoDB/MySQL). The AI module is implemented in Python for efficient resume processing and analysis. The repository is organized into modular folders for the frontend, backend, AI engine, documentation, and additional resources.

Along with the project modules, Career Verse includes two detailed reports: a Beginner Report, which explains the project in an easy and foundational manner for new learners, and a Completion Report, which covers the full technical implementation, architecture, challenges, and outcomes of the project. Additionally, the repository contains your published research paper, offering academic validation and a deeper understanding of the innovative concepts used in the system.

To set up the project locally, users can clone the repository and install the dependencies for each module. The backend requires a .env file containing the MongoDB URI, JWT secret, port number, and optional AI API keys. The platform can be deployed using services like Vercel or Netlify for the frontend and Render, Railway, or AWS for backend hosting. Career Verse is open-source under the MIT License, welcomes community contributions, and aims to evolve with future features such as an interview preparation chatbot, resume builder, and AI-driven job recommendations.
